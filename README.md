# Portafolio de Arley Yesid Bulla

## Descripción del proyecto y su funcionalidad

Portafolio personal responsivo de Arley Yesid Bulla, desarrollador web frontend. El sitio presenta una introducción personal, sección de habilidades técnicas, proyectos destacados y un formulario de contacto. El diseño es completamente adaptable a distintos tamaños de pantalla: escritorio (1440px), tableta (768px) y móvil (320px).

## Tecnologías y técnicas utilizadas

- **HTML5** — Estructura semántica con etiquetas `<section>`, `<article>`, `<nav>`, `<main>`, `<footer>`, `<ul>`, `<li>`
- **CSS3** — Diseño responsivo con Flexbox, pseudo-clases `:hover`, gradientes CSS, transiciones y animaciones
- **Consultas de medios (Media Queries)** — Diseño adaptable para resoluciones de 1440px, 768px y 320px
- **Tipografías personalizadas** — Archivo Black y Open Sans cargadas con `@font-face`
- **BEM** — Metodología de nomenclatura de clases CSS para un código organizado y mantenible
- **Git y GitHub** — Control de versiones y despliegue del proyecto
